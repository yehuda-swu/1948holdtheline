# 1948: Hold the Line · Version 6

An educational strategy game designed for StandWithUs UK Explore learners.

## What's new

* Cinematic home screen featuring the supplied StandWithUs UK and Explore logos.
* Clear mission briefing at the start of each of eight historical chapters.
* One decision per chapter, with three actions and clearly explained costs.
* More dramatic animated battle results with simple explanations.
* Optional original ambient sound, off by default.
* Responsive mobile layout and a prominent restart button.

Game units, battles and military results are fictional teaching mechanics. Historical events are distinguished from gameplay.

## Publish to GitHub Pages

Upload `index.html` to the root of the existing `yehuda-swu/1948holdtheline` repository and replace the existing file. GitHub Pages should be configured to publish the main branch root. No external dependencies are required.

Commit message: `Make missions clearer and add cinematic battle reports`
